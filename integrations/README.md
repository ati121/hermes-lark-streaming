# OpenViking 服务端扩展迁移

从 v1.20 起，插件不再使用服务端进度扩展。保持 OpenViking 官方镜像、启动入口和
配置即可；插件只在 Hermes 自动预取开始时显示“OpenViking · 查询记忆”，结束或
超时后恢复模型状态。现有普通接口不实时报告内部阶段，因此不单独显示意图分析、
记忆检索或准备提示。

## 已安装 v1.12–v1.13 扩展的部署

1. 更新飞书插件到 v1.20 或更新版本。
2. 从 OpenViking Compose 中移除 `hermes-progress` 挂载，以及指向
   `with-progress.sh` 的 `entrypoint` 覆盖，恢复官方镜像的默认入口。
3. 使用原有官方镜像重建 OpenViking 容器，使旧容器层中的注入代码一并移除。
   保留现有数据卷、认证配置和其他服务设置，不需要为了迁移而升级镜像。
4. 核对服务健康、官方启动入口以及扩展挂载已移除后，可归档旧辅助脚本。

仅重启旧容器不会移除容器层中已有的补丁。若此前把扩展构建进自定义镜像，
需要恢复官方镜像或移除对应构建步骤后重新构建。
